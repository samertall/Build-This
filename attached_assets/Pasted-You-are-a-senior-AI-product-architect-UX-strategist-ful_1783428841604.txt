1. PRODUCT VISION
==================================================

Build an intelligent UX and digital product workflow platform that converts scattered project material into structured, actionable product-design outputs.

The platform should act as an AI-powered UX co-pilot that helps teams move from:

Research → Analysis → UX Strategy → User Flows → Feature Priorities → Wireframes → Content → Team Tasks → Presentations

The main value proposition is:

“From scattered UX inputs to clear product execution—faster, smarter, and aligned.”

The platform must reduce repetitive UX planning, improve cross-functional alignment, shorten the research-to-decision cycle, and make UX recommendations directly actionable.

Do not build a generic chatbot or a static dashboard.

Build a structured agentic product with visible workflows, review checkpoints, reusable outputs, project history, collaboration, and export capabilities.

2. CORE PROBLEM
==================================================

Modern digital product work is fragmented, repetitive, and slow.

UX and product teams manage:

- Research notes
- User feedback
- Stakeholder requests
- Business goals
- Existing content
- Figma files
- Screenshots
- Analytics
- Competitor references
- Product requirements
- SEO requirements
- Development tasks
- Marketing requirements
- Project-management tickets

These inputs are usually distributed across disconnected tools.

This creates:

- Scattered project context
- Unclear requirements
- Repeated manual synthesis
- Missed user insights
- Weak alignment between design and business goals
- Generic UX recommendations
- Slow decision-making
- Ambiguous development tasks
- Content gaps
- Increased rework
- Delayed product delivery

The core challenge is:

“How can teams move from messy project inputs to clear UX execution without losing user context, business objectives, evidence, or team alignment?”

==================================================
3. PRODUCT SOLUTION
==================================================

The platform must analyze project inputs such as user needs, business goals, content, research, screenshots, design files, and existing product material.

It must then:

1. Extract and organize the project context.
2. Summarize research and stakeholder inputs.
3. Identify pain points, risks, gaps, constraints, and opportunities.
4. Separate evidence from AI assumptions.
5. Create problem statements and UX hypotheses.
6. Recommend UX and product improvements.
7. Generate personas, jobs-to-be-done, and user segments when appropriate.
8. Create user journeys and task flows.
9. Prioritize features.
10. Suggest information architecture.
11. Generate wireframe directions.
12. Recommend UX writing, content, accessibility, CX, and SEO improvements.
13. Convert approved recommendations into team-ready tasks.
14. Generate professional PowerPoint presentations.
15. Export the final outputs to external workflow tools.

The experience should feel like a structured digital UX consultancy rather than a conversational assistant.

5. AGENTIC AI ARCHITECTURE
==================================================

Create a coordinated multi-agent workflow.

Each agent must have a defined responsibility, input schema, output schema, and quality-control step.

Agent 1: Project Context Agent

Responsibilities:

- Read uploaded and connected content.
- Identify the project name, industry, product type, audience, business model, goals, constraints, timeline, and stakeholders.
- Create a structured project brief.
- Identify missing information.
- Ask only high-value clarification questions.

Outputs:

- Project brief
- Known facts
- Missing information
- Constraints
- Source inventory
- Initial assumptions

Agent 2: Research Synthesis Agent

Responsibilities:

- Analyze research notes, interviews, surveys, feedback, reviews, and analytics.
- Cluster similar findings.
- Detect recurring pain points.
- Separate direct evidence from interpretations.
- Identify contradictory evidence.
- Produce source-linked insights.

Outputs:

- Research summary
- Insight clusters
- Pain-point list
- User needs
- Evidence table
- Confidence score
- Research gaps

Agent 3: Problem Framing Agent

Responsibilities:

- Convert research into clear problem statements.
- Create “How might we” questions.
- Identify root causes.
- Map user problems to business impact.
- Define measurable outcomes.

Outputs:

- Problem statements
- Root-cause analysis
- How-might-we questions
- UX hypotheses
- Business implications
- Recommended success metrics

Agent 4: UX Strategy Agent

Responsibilities:

- Recommend product and UX improvements.
- Connect each recommendation to evidence.
- Evaluate expected user value, business value, feasibility, and risk.
- Detect accessibility, usability, conversion, CX, and SEO opportunities.

Outputs:

- UX opportunity list
- Strategic recommendations
- Risks
- Quick wins
- Long-term opportunities
- Evidence and rationale

Agent 5: Journey and Flow Agent

Responsibilities:

- Generate current-state and future-state user journeys.
- Create task flows and user flows.
- Identify friction points, emotional states, touchpoints, and opportunities.
- Support multiple personas and scenarios.

Outputs:

- Journey maps
- User flows
- Task flows
- Entry and exit points
- Edge cases
- Failure and recovery paths

Agent 6: Feature Prioritization Agent

Responsibilities:

- Convert opportunities into features.
- Score features using RICE, MoSCoW, impact-versus-effort, or a custom framework.
- Allow the user to change scores manually.
- Explain the prioritization.

Outputs:

- Prioritized backlog
- MVP features
- Future-phase features
- Scoring matrix
- Dependencies
- Risks
- Recommended roadmap

Agent 7: Information Architecture Agent

Responsibilities:

- Recommend navigation structures.
- Generate sitemaps.
- Define content hierarchy.
- Identify duplicate or missing sections.
- Recommend labels and taxonomy.

Outputs:

- Sitemap
- Navigation model
- Page hierarchy
- Content groups
- Naming recommendations

Agent 8: Wireframe Direction Agent

Responsibilities:

- Generate wireframe concepts based on approved flows and requirements.
- Describe screen structure and component hierarchy.
- Create low-fidelity visual concepts where supported.
- Avoid pretending that generated concepts are validated designs.

Outputs:

- Screen list
- Layout recommendations
- Component requirements
- Interaction notes
- Responsive rules
- Wireframe previews
- Figma-ready design brief

Agent 9: Content, CX and SEO Agent

Responsibilities:

- Review product content and user-facing messages.
- Identify missing, duplicated, unclear, or low-value content.
- Recommend UX writing.
- Recommend page titles, headings, descriptions, keywords, calls to action, and structured content.
- Review the end-to-end customer experience.

Outputs:

- Content inventory
- Content-gap report
- UX copy suggestions
- SEO recommendations
- CTA recommendations
- CX improvement opportunities

Agent 10: Task Orchestration Agent

Responsibilities:

- Convert approved outputs into actionable work items.
- Create separate tasks for design, development, content, marketing, research, and QA.
- Add priorities, owners, dependencies, estimates, acceptance criteria, and source references.

Outputs:

- Epics
- User stories
- Design tasks
- Development tickets
- Content tasks
- Marketing tasks
- QA tasks
- Acceptance criteria
- Definition of done

Agent 11: Presentation Agent

Responsibilities:

- Convert project information and approved outputs into professional presentations.
- Extract and reuse project images.
- Generate presentation narratives suitable for executives, clients, employers, investors, or internal teams.
- Produce editable PowerPoint files.

Outputs:

- Presentation outline
- Slide copy
- Visual recommendations
- Speaker notes
- Editable PPTX
- PDF version
- Presentation preview

Agent 12: Quality and Governance Agent

Responsibilities:

- Check generated outputs for contradictions, unsupported claims, missing evidence, duplication, vague recommendations, and incomplete tasks.
- Validate consistency across research, flows, features, tasks, and slides.
- Flag low-confidence output.
- Require human approval before publishing or exporting critical deliverables.

Outputs:

- Quality report
- Conflicts
- Missing evidence
- Confidence indicators
- Approval requirements
- Revision recommendations
